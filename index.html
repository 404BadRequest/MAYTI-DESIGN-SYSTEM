19 · Reglas

Do / Don’t

Do

  • PNG oficiales sin alterar (productos solo en claro)
  • RecordList + ListPager + EmptyState
  • MapLibre + CoveragePanel para SIG
  • Dialog RecordDrawer + toasts + shimmer
  • Seguir stack/patterns.md

Don’t

  • Recharts / Chart.js / TanStack / AG Grid
  • Mapas o logos de producto en fondo navy
  • Listas vacías sin CTA / sin skeleton
  • window.confirm / alert para UX de producto
  • Purple-on-white genérico
